# Website Ulang Tahun 🎂

Surat digital ulang tahun: amplop bersegel, surat, alasan sayang, galeri foto, hitung hari, dan kue yang bisa ditiup.

## Cara edit
Buka **`config.js`** lalu ganti: nama, tanggal, isi surat, alasan, dan keterangan foto.
Untuk foto, taruh file di folder `photos/` (misal `foto1.jpg`) lalu tulis `src:"photos/foto1.jpg"` di `config.js`.

Warna dan tampilan ada di `style.css`.
Cek hasilnya dengan membuka `index.html` di browser.

## Cara upload ke GitHub + online gratis (GitHub Pages)
1. Buat akun di github.com, lalu klik **New repository**, beri nama (misal `ulang-tahun`), pilih **Public**, klik **Create**.
2. Klik **uploading an existing file**, tarik semua isi folder ini (index.html, style.css, script.js, config.js, folder photos), lalu **Commit changes**.
3. Buka **Settings → Pages**. Di *Branch* pilih `main` dan folder `/ (root)`, klik **Save**.
4. Tunggu 1-2 menit. Linknya muncul: `https://USERNAME.github.io/ulang-tahun/`
5. Kirim link itu ke pacarmu 💕

Mau ganti isi setelah online? Edit `config.js` langsung di GitHub (ikon pensil), klik Commit, dan tunggu sebentar.

Tips: repo Public artinya siapa pun yang tahu linknya bisa buka. Jangan taruh info pribadi yang sensitif.
